## Решения PO (2026-11-08, AskUserQuestion)
1. **Данные/права:** «Можно прям реальные данные. Это для меня только» — реальные названия систем, регионов, юнитов,
   лидеров и топология карты допустимы в репозитории. Арты, сканы, тексты карт и правил правообладателя — по-прежнему нет
   (вопрос формулировался с этим ограничением).
2. **Срез правил:** «Раунд + активация» (рекомендованный вариант).
3. **AI-сторона:** «Авто-пас» — сервер применяет за AI детерминированный пас через тот же конвейер команд и журнал.
