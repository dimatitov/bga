# Implementation plan — SWR-005

Детальные планы: [`plan-backend.md`](plan-backend.md), [`plan-frontend.md`](plan-frontend.md); тест-дизайн — [`test-cases.md`](test-cases.md);
факты игры — `docs/game-rules/rebellion-reference.md`. **При расхождении приоритет:** `specification.md` (Rules ревизия 2,
Clarifications, Data clarifications) → этот файл → планы лидов. Главные отличия от планов, принятые после справочника:
пас постоянный до конца фазы (`passed: {rebels, empire}` вместо `consecutivePasses`); нет ключа `systemHasOwnLeader`, есть
`leaderCannotActivate`; раскрытие базы — наземными юнитами Империи при `FINISH_ACTIVATION`; победа Империи — нет **никаких**
юнитов Повстанцев; база видна всем после `outcome`; `details` += `reputation`; handoff-view += `rulesEngine`.
