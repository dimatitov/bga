# Request — SWR-005C

Источник: запрос Product Owner (передан главной сессией 2026-11-20, «SWR-005C — Rules Knowledge Foundation»).
PO сформулировал его как задачу «до SWR-006»; фактически SWR-006 (AI Commander v0) к моменту старта почти завершена
(не закоммичена в основном checkout). Поэтому база знаний должна обслуживать и **следующую итерацию** AI Commander, а аудит
должен отметить поведение SWR-006, конфликтующее с официальными правилами, после того как SWR-006 будет влита
(см. `specification.md`, A-6). Файлы, которые меняет незакоммиченная SWR-006, в этой задаче не редактируются.

## Запрос PO (дословно, в переводе на рабочий язык задачи сохранены формулировки)

> **Цель** — один проверяемый набор правил Star Wars: Rebellion для трёх потребителей: (1) Game Core — реализация и проверка
> механик; (2) AI Commander — понимание целей, ограничений и доступных действий; (3) Rules Assistant — ответы на вопросы
> пользователя со ссылками на источники.
>
> **Источники** — официальные английские документы FFG:
> Learn to Play https://images-cdn.fantasyflightgames.com/filer_public/0b/07/0b07601a-6ac3-4333-ac41-b6d1b9a979da/sw03_learn_to_play_web.pdf ;
> Rules Reference https://images-cdn.fantasyflightgames.com/filer_public/d9/76/d97645d4-3973-41b6-ad78-6c9b927d3bc1/sw03_rules_reference_web.pdf ;
> FAQ v2.1 https://images-cdn.fantasyflightgames.com/filer_public/53/ac/53ac8f34-2d3b-4ec1-bfe8-816811756692/sw03_faq_v2_1.pdf .
> Проверить, что источники актуальны и применимы. Только базовая игра, без Rise of the Empire.
>
> **Задачи** — 1) изучить существующие документы правил и реализацию правил в проекте; 2) спроектировать расширяемый формат
> базы знаний для нескольких настольных игр; 3) построить структурированный справочник правил Rebellion с id, категориями,
> исключениями и ссылками на страницы источников; 4) разделить официальные правила, интерпретации, подтверждённые
> разъяснения (FAQ) и заметки о неполной реализации; 5) матрица покрытия: правило → реализация → тесты → статус;
> 6) аудит существующего среза SWR-005 против официальных правил; 7) зафиксировать каждое найденное расхождение, не исправляя
> крупные механики в этой задаче; 8) подготовить интерфейс поиска по базе знаний для будущего Rules Assistant;
> 9) подготовить способ давать AI Commander релевантные правила без отправки полного PDF в каждом запросе;
> 10) автоматические проверки структуры, ссылок, id и покрытия правил.
>
> **Ограничения** — не считать автоматически сгенерированные описания правил надёжными без проверки по первоисточнику;
> неоднозначные случаи держать как `needs-review`; не заменять формальные правила движка текстовыми инструкциями для GPT;
> не смешивать базовую игру с дополнениями; НЕ класть полные тексты правил правообладателя в ПУБЛИЧНЫЙ репозиторий — только
> ссылки, собственные структурированные описания и короткие необходимые цитаты; использовать существующую архитектуру,
> агентный workflow и систему приёмки.
>
> **Результаты** — расширяемая проверяемая база знаний правил в репозитории; матрица покрытия реализованных механик; список
> расхождений; описание API/сервисного интерфейса получения правил; план реализации Rules Assistant; `delivery-report.md`
> с результатами проверок.
