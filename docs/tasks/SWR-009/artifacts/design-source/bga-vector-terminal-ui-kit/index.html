08 / MAP

Карта, легенда и визуальные состояния

Маршруты сдержанные; регионы обозначены штриховой границей без заливки. Число у глифа — количество фигур, представленных именно этим маркером, не «сила армии». Если рядом флот и наземные силы, это отдельные глифы и счётчики. Мини-пример ниже показывает визуальные коды, не игровую топологию; позиции и legalActions берутся из данных карты.
