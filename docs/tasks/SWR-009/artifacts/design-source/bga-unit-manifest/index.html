Ограничение данных: в приложенных игровых скриншотах есть агрегированные счётчики, но нет полного состава фигур для Корусанта. Поэтому состав 6 + 3 на этой странице явно помечен как демонстрационный пример из референса, а не как содержимое конкретной партии. В production-компонент передаются только состав и лидеры, разрешённые серверным PlayerView.
