## Contracts (frozen before parallel work)

Полные сигнатуры — PB §2 (C-1..C-10) и §6; всё изменение платформы **аддитивно**:

- **C-1** `packages/platform/src/rules-context.ts` (новый): `RulesSelectionInput{actor, phase, commandTypes, tags, maxChars}`,
  `RulesContextResult{text, ruleIds, truncated, rulesVersion}`, `RulesContextProvider{rulesVersion, requiredChars,
  selectRules}`, `GameRulesSupport{knowledgeBaseDir, createRulesContextProvider}`, `KnowledgeBaseSource`,
  `rulesSelectionInputOf(point, maxChars)` — вход только из `actor`, `phase`, `rulesQuery` (кандидаты не читаются, QD-7).
- **C-2** `ServerGameModule.rules?: GameRulesSupport` (optional).
- **C-3** `AutomationDecisionPoint.rulesQuery?: {commandTypes, tags}` (optional, только публичная информация);
  `AutomationFallbackCode` + `'AI_PROMPT_TOO_LARGE'` (в конец enum).
- **C-4** Rebellion `rulesQueryFor(view)`: `activation===null → [ACTIVATE_SYSTEM, PASS]`, иначе `[FINISH_ACTIVATION,
  MOVE_PIECES]`; теги `base-hidden|base-revealed`, `opponent-passed`.
- **C-5** `@bga/platform/rules-kb`: `buildRulesContext` + опции `excludeStatuses`, `tagRuleIds` (default — прежнее
  поведение); `createKnowledgeBaseRulesProvider(source, {pinnedRuleIds, tagRules})`; `rulesVersion =
  <gameId>@<formatVersion>:<sha256(canonicalJson(entries sorted by id))[0..12]>` (QD-5), SHA-256 на чистом TS.
- **C-6** Rebellion `rebellionRules`: KB `packages/games/rebellion/knowledge`, pinned `rebellion:impl.engine-scope`
  (новая запись `ai:'core'`, решение F-7), таблица тегов.
- **C-7** env: `AI_COMMANDER_RULES_CONTEXT=on|off` (on), `AI_COMMANDER_RULES_MAX_CHARS` (1000..12000, 6000),
  `AI_COMMANDER_MAX_PROMPT_TOKENS` (4000..64000, 16000; верхняя оценка токенов); `AppConfig.knowledgeBaseRoot` (не из env).
- **C-8** `apps/api/src/rules-context/`: `createRulesContextRegistry` (загрузка при старте iff `openai`+`on`, fail fast,
  `maxChars < requiredChars` → ошибка старта), тестовый `loader`.
- **C-9** AI layer: `AIDecisionContext.rules?`/`rulesAccounting?`; блок правил перед `Game (data)` + 
  `COMMANDER_RULES_INSTRUCTIONS` только при наличии правил (off → побайтно SWR-006); `fitCommanderPrompt`
  (full → reduced → dropped → `AI_PROMPT_TOO_LARGE`, без вызова/резерва); бюджет SWR-005B/006 без изменений, резерв
  считается по полному промпту; `AiUsage` + 9 колонок правил (миграция `20261120120000_ai_usage_rules`);
  `summarizeCostByRules`.
- **C-10** `CommanderRunContext.rules`, `buildCommanderContext` (общий для стратегии и benchmark).
- **Wire dev-диагностики** (PB §6): `GET /api/dev/ai/sessions/:sessionId/decisions` → `AiSessionDecisionsResponseSchema`
  (`packages/platform/src/ai-diagnostics.ts`); только `nodeEnv !== 'production'` + loopback; без `budgetKey`, `reason`,
  текста промпта/правил.
- **DISC-009**: `runStateChecks` (`packages/games/rebellion/src/rules/core/state-checks.ts`) — единственная точка раскрытия
  (после каждой принятой команды в `applyCoreCommand` и в `createCoreGame`); во время активации Империи откладывается до
  `FINISH_ACTIVATION`; порядок `ACTIVATION_FINISHED → BASE_REVEALED → GAME_OVER`; схема state не меняется; DISC-009
  `decision: "fixed"`.
- **Не меняются:** `AutomationRunSummarySchema`, `SessionResponse`, механизм бюджета, схема ответа модели, схема state
  Rebellion, `buildDevTestPrompt`.
