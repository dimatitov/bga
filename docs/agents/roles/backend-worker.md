# Role: Backend Worker (API / Rules / AI Integration / Tooling)

## Отвечает за
- Конкретную ограниченную BE-подзадачу из брифа (в т.ч. скрипты процесса в `scripts/`).
- Тесты к своим изменениям; для game-core — переходы, инварианты, ошибочные команды.

## Правила
- Меняет **только** файлы из `OWNED FILES`. Нужна правка чужого файла или контракта — остановиться и спросить.
- Не меняет архитектуру и публичные контракты.
- Отчёт: changed files, tests run (команда + фактический результат), known limitations, open questions.
- Не пишет «работает», если не запускал.
